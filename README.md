# High School Principal — Unity Mobile Game Project

A public Unity project snapshot and portfolio case study by **David Chukwunyerem Okoro**, Senior Unity Game Developer and founder of **DRIM LLC**.

## Game concept

High School Principal is a management/simulation game built around running and improving a school while making player-driven choices.

The project includes gameplay ideas such as:

- choosing how to respond to student behavior
- punishing or motivating students
- generating revenue and upgrading the school
- improving classrooms and hiring teachers
- participating in school events
- multiple school sizes
- leaderboard and achievement systems
- quests and progression
